# Space Invaders

Videojuego 2D desarrollado en Unity utilizando C#.

## Características
- Tres niveles de dificultad.
- Enemigos con diferentes comportamientos.
- Sistema de puntuación y vidas.
- Power-ups temporales.
- Música y efectos de sonido.
- Menú principal y sistema de pausa.

## Tecnologías
- Unity
- C#

## Controles
- Movimiento: A / D
- Disparo: Espacio
- Pausa: Escape
